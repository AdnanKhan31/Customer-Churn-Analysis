# Customer Churn Analysis – End-to-End Data Analytics

## 📌 Project Overview

This project is an end-to-end data analytics project based on the Telco Customer Churn dataset. It focuses on analyzing customer churn patterns, understanding customer behavior, identifying factors associated with customer attrition, and exploring opportunities to improve customer retention.

The analysis follows a complete data analytics workflow, starting with data cleaning and preparation using Python, followed by SQL-based business analysis and interactive Power BI visualization.

The goal is to transform customer data into meaningful business insights that can help businesses understand why customers leave and identify areas where retention strategies can be improved.

## 🎯 Business Objective

The primary objective of this project is to analyze customer churn and identify the factors that influence customer retention and attrition.

The analysis focuses on questions such as:

- What is the overall customer churn rate?
- Which customer segments have higher churn rates?
- How does customer tenure relate to churn?
- Which contract types experience higher customer attrition?
- How do payment methods and billing patterns relate to churn?
- Which services are associated with higher or lower churn?
- What customer characteristics distinguish churned customers from retained customers?
- Which areas may require attention to improve customer retention?

## 🔄 Project Workflow

**Raw Data → Python Data Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights & Recommendations**

### 1. Data Cleaning & Preparation

The Telco Customer Churn dataset was prepared using Python.

The data preparation process included:

- Reviewing the dataset structure
- Checking missing and blank values
- Identifying and checking duplicate records
- Handling missing values where required
- Reviewing column names and data types
- Preparing the cleaned dataset for further analysis

### 2. Data Storage & SQL Analysis

The prepared customer churn data was imported into PostgreSQL and analyzed using SQL.

Business-focused SQL analysis was performed to evaluate:

- Overall customer churn
- Churn rate and customer distribution
- Churn across different contract types
- Customer tenure and churn patterns
- Payment methods and churn behavior
- Monthly charges and total charges
- Internet services and additional subscriptions
- Customer characteristics and retention patterns

SQL queries were used to organize, summarize, and examine customer behavior across different segments.

### 3. Power BI Dashboard

The analyzed customer churn data was used to develop an interactive Power BI dashboard.

The dashboard focuses on important business areas, including:

- **Overall Churn** – Total customers, churned customers, retained customers, and churn rate
- **Customer Segmentation** – Churn distribution across different customer groups
- **Contract Analysis** – Comparison of churn across contract categories
- **Payment Analysis** – Customer churn patterns across payment methods
- **Service Analysis** – Relationship between subscribed services and customer churn

The dashboard is designed to make customer retention patterns easier to understand and support data-driven decision-making.
